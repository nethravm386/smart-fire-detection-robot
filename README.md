# Smart Fire Detection Robot using IoT

## Project Overview
The Smart Fire Detection Robot is an IoT-based robotic system designed to detect fire and smoke using sensors. It uses an Arduino Uno as its main controller and an IoT module to send alerts to users.

## Objectives
- Detect fire using a flame sensor.
- Detect smoke using an MQ-2 sensor.
- Avoid obstacles using an ultrasonic sensor.
- Generate alerts using a buzzer and LED.
- Monitor detection status through an IoT dashboard.

## Hardware Components
- Arduino Uno
- MQ-2 Smoke Sensor
- Flame Sensor
- HC-SR04 Ultrasonic Sensor
- Motor Driver
- DC Motors
- ESP8266 NodeMCU
- Buzzer
- LED

## Software Requirements
- Arduino IDE
- Embedded C/C++
- Blynk IoT
- GitHub

## Working Principle
The robot moves while avoiding obstacles. The flame and smoke sensors monitor the surroundings. When smoke or a flame is detected, the robot activates an alert using a buzzer and LED. The detection information is also sent to a mobile dashboard through Wi-Fi.
